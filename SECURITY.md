# Security

This repository is the static bursar.world website. It holds no keys and talks to no contract.

Report vulnerabilities in the website, the console, the facilitator or the contracts through the
policy in the main repository:
[github.com/bursar-world/bursar/security/policy](https://github.com/bursar-world/bursar/security/policy),
or by email to security@bursar.world. Please do not open a public issue for a vulnerability.
